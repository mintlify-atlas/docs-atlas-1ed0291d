MejoraGemeseg is the internal operations platform for GEMESEG (Ecuador) and its affiliated companies. It brings together project and task management, a full human-resources suite, custodias logistics, cacao inventory tracking, a sales CRM, and an AI chat assistant — all under one multi-tenant roof with per-company branding.

## Get Started in 4 Steps

<Steps>
  <Step title="Clone and install dependencies">
    Clone the repository and install Node.js dependencies for both `backend/` and `frontend/`.
  </Step>
  <Step title="Configure environment variables">
    Copy `.env.example` to `.env` and set `DATABASE_URL`, `JWT_SECRET`, and optionally `GITHUB_TOKEN` for AI features.
  </Step>
  <Step title="Run migrations and seed data">
    Run `npx prisma migrate dev` then `node prisma/seed.js` to create the database schema and sample users/projects.
  </Step>
  <Step title="Start the servers">
    Start the backend (`npm run start:dev` on port 3000) and frontend (`npm run dev` on port 5173). The Swagger API docs are at `http://localhost:3000/docs`.
  </Step>
</Steps>

<Note>
  The production deployment runs on **Railway** (backend), **Vercel** (frontend), and **Supabase** (PostgreSQL). See [Deployment](/deployment) for full configuration details.
</Note>
