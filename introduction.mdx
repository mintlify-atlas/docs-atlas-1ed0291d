MejoraGemeseg is the internal digital workspace for **GEMESEG (Ecuador)** and its affiliated companies — including **Mikacao S.A.** Each company operates in a fully isolated tenant, with its own branding, users, and data, all managed through a single monorepo deployment. The platform is built for desktop web use and follows a Scrum methodology with 1–2 week sprints.

## What the platform covers

MejoraGemeseg consolidates the day-to-day operations that previously lived in spreadsheets, email threads, and disconnected tools. The following modules are available in production:

| Module | Description |
|--------|-------------|
| **Projects / Kanban** | Create projects, manage members with roles (OWNER, MEMBER, VIEWER), and track tasks across a 4-column Kanban board (Por hacer → En progreso → En revisión → Completado). |
| **HR / RRHH** | Personnel records, certifications, document reviews, movement tracking, and compliance checklists for field staff. |
| **Custodias** | Assignment and logistics tracking for custody operations (Hacienda, Puerto, VIP types). |
| **Cacao** | Cacao supplier and client management, lot receptions, settlements, and payables for Mikacao S.A. |
| **Sales / Ventas** | Leads, client visits, sales contracts (with SignWell e-signature integration), and sales goals. |
| **AI Chat** | A floating chat drawer powered by GitHub Models (`gpt-4o-mini`) with per-agent conversation history, a 50-message/day rate limit, and context-aware responses based on the current page. |
| **Tool Inventory** | Software tool catalog with user assignments, license keys, version tracking, and an audit log. |
| **Admin Panel** | User CRUD, project health statistics, and company management — restricted to ADMIN role. |

## Technology stack

| Layer | Technology |
|-------|------------|
| Backend | NestJS v11 + TypeScript |
| ORM | Prisma v7 (`@prisma/adapter-pg`) |
| Database | PostgreSQL 17 |
| Authentication | Passport.js (JWT, 7-day expiry) + bcryptjs (salt 10) |
| Frontend | React 18 + Vite + TypeScript |
| HTTP client | Axios (with JWT interceptor) |
| Validation | class-validator + class-transformer (backend), Zod (frontend) |
| PDF generation | PDFKit (custodias: order sheets, payroll, payment roles) |
| AI | GitHub Models (`gpt-4o-mini`) |
| Styles | Custom CSS with GEMESEG corporate palette |
| Deploy | Railway (backend) + Vercel (frontend) + Supabase (DB) |
